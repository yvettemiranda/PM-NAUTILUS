# 界面改版（2026-11-04）

本次只改 `web/index.html` 和 `web/styles.css`，只动页面外观。`app.js`、全部 Python、配置、依赖和测试文件均未改动。

## 变化

- 浅色、朴素的工具风格：米白底、白卡片、细灰线，只用一个主色（原深绿），红绿只表示盈亏。去掉渐变、阴影、圆角胶囊等装饰。
- 宽屏（≥1100px）分两栏：左侧固定显示资金和收益曲线，右侧是持仓、记录和市场；窄屏仍为单栏，手机顶栏不再固定在屏幕上方。
- 收益曲线按累计盈亏的正负显示绿或红，背景有浅色网格线。
- “暂无报价 / 赎回待核查”提示原先是整行黄色提示条，现在改成“总资产估算”旁的一个小标记，点击后才显示原文；没有这类情况时不显示。`#valuation-note` 的内容和显示条件仍由 `app.js` 原逻辑控制，完整说明仍在“资金明细”中。
- 持仓展开后的指标改为四列，配置页改为分组卡片；LIVE 按钮为红字，钱包卡片顶部有红线，与 TEST 区分。

## 保留

HTML 只增加了布局容器和提示标记的外层，143 个元素 ID 及 62 个按钮、输入框的全部属性与改版前逐个一致；所有按钮的处理函数和接口调用不变。没有引入字体下载、图片、外部脚本或新依赖。

## 检查

- 122 项页面测试通过。
- 在本地模拟接口上，用 Chromium 检查了 1440px 和 390px 两种宽度下的持仓、记录、市场、配置、展开详情、LIVE 钱包页和空账户：无横向溢出，控制台无报错。截图数据为模拟数据，不是服务器账户。
- Python 测试由 CI 运行。
