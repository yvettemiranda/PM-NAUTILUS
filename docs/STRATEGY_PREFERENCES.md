# 可选策略与账本分析

在网页的策略设置中，四项新设置都默认关闭。已有账本以及旧版偏好文件缺少这些字段时，读取为关闭。账户只保存开启的新增项。偏好导出会列出全部设置，导入接受旧版 15 项或含新增项的文件。TEST 的每个账户与 LIVE 分别保存各自的选择。

| 设置 | 开启后的行为 |
| --- | --- |
| 纳入独立二元市场 `includeIndependentMultiMarkets` | 非负风险事件包含多个市场时，把每个市场作为二元市场处理。按市场 ID 独立仲裁和记账，保留原事件 ID 用于链接和展示。 |
| 纳入增强负风险市场 `includeAugmentedNegRisk` | 纳入具名选项，跳过 Other 和未命名占位。仍按原事件的结果数判断是二元、三元还是多元。 |
| 按市场独立开仓周期 `cyclePerMarket` | 按 Condition 分别开仓、记录目标卖价、观察止损和结算。同一个市场的两个结果仍按同一周期仲裁。每个周期使用设置中的每轮金额，多个市场可能同时占用资金。 |
| 买入只吃最优卖档 `buyBestLevelOnly` | 每笔买单以计划时的最优卖价为限价，允许部分成交，保留预算、费用、最小订单和价格过滤。提交前最优卖价变化时，重新评估买入计划。TEST 用完本账户在该公开档位的模拟深度后，等待该档补量或真实盘口变化。 |

市场扩展选项在共享扫描完成后加入候选市场。交易协议、官方类别、时长、进度和买入报价等检查继续适用。关闭扩展选项会停止相关市场的新买入，已有持仓仍可卖出和结算。切换周期选项时，已有仓位和未完成订单继续使用原周期，新开仓需避免与仍在处理的旧周期重叠。已有目标价和止损参数沿用入场时保存的值。 [Polymarket 增强负风险市场说明](https://docs.polymarket.com/concepts/negative-risk#augmented-negative-risk)

纳入独立二元市场还需要勾选「二元」。增强负风险事件有四个或更多结果时，需要勾选「多元」才会进入候选。

## 手续费

直接吃盘口的成交属于 taker。费用取决于市场自己的费率和费率指数。在 Polymarket 当前公开的公式 `份数 × 费率 × 价格 × (1 − 价格)` 下，1–3¢ 买入时，费率为 4% 的市场每笔买费约为成交额的 3.88%–3.96%，费率为 7% 的市场约为 6.79%–6.93%，精度截断前。卖出若同样吃盘口，也按卖出成交价格收费。只吃最优一档可以限制买入价格和成交深度，每单位成交仍按该市场的费率结算。 [Polymarket 手续费](https://docs.polymarket.com/trading/fees)

## 分组报告

在安装了本项目锁定依赖的环境里，指定单个账户的 SQLite 账本。下面的命令以 TEST 2 为例。

```sh
uv run --frozen python scripts/cohort_report.py runtime/server/TEST/accounts/2/state.sqlite
```

在按部署手册安装的 Docker 服务器上，可在运行中的容器内生成同一个账户的报告。

```sh
sudo sh -c 'cd /opt/pm-nautilus && docker compose exec -T app .venv/bin/python - /data/TEST/accounts/2/state.sqlite < scripts/cohort_report.py'
```

输出为 JSON，按买入实际成交价所在的整分区间、UTC ISO 周和账本保留的类别组合分组。例如 1¢ 桶包括 1.0¢ 至低于 2.0¢ 的成交。多标签保留为一个组合，各组之间不会重复计量。

- 目标价卖出率按份额计，用能与买入批次核对且达到冻结目标价的卖出份额除以该组买入份额。平均卖出天数按能核对的目标卖出与止损卖出份额加权。
- 结算归零比例按已结算份额计算，同时列出占全部买入份额的比例。买费和卖费使用账本中的成交费用。
- 未平仓估值按账本最后保存的买盘深度逐档估算，TEST 扣除本账户的模拟消耗。估值扣除按账本费率估算的卖费，并与有定价覆盖部分的含费买入成本比较。报告标记快照时点、缺报价与深度不足的份额和成本。快照反映当时账本保存的数据，可能早于当前行情。

脚本使用只读 SQLite 连接。LIVE 账本缺少可用盘口快照时，报告仍可提供成交和手续费统计。
