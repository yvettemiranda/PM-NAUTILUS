# LIVE 准备检查

本文说明 `main` 当前实现的接入与保护边界，固定基准和应用版本见 [版本维护](VERSIONS.md)。最近一次应用验证见 [VALIDATION](VALIDATION.md)，服务器状态以 [HANDOFF](../HANDOFF.md)记录的验收时点和当次只读核查为准。历史钱包、地区或余额结果不能复用为新服务器准入证明。

## 钱包和账户核对

当前完整接入路径支持程序已实现的 EOA（签名类型 0）及唯一 owner、阈值 1 的 Safe（类型 2）；Deposit Wallet（类型 3）未实现完整路径。账户是否具有官方交易资格需独立核对，程序支持某种签名类型不等于该账户已获准交易。

首次安装自己的 HTTPS 和网页登录后，LIVE 页提供导入、解锁和检查。密钥只输入自己确认的本程序 HTTPS 页面，不发送到聊天、GitHub 或截图；助记词原文不落盘，钱包加密文件保存在持久卷 `wallet/live.vault`。解锁后进程内存中持有签名密钥。

资金地址留空时，程序只读发现已有 Safe，并严格核对 factory 派生、部署状态、唯一 owner 及阈值；失败不猜测 EOA。已保存钱包不自动改绑。只有从未有 LIVE 交易、未启用且无未知在途状态的空白钱包，才能由用户输入密码明确清除后重新导入。

网页检查核对服务器地区、认证、资金与手续费条件、交易及赎回授权、全部开放挂单和实际钱包份额。本程序已知权利按本次固定区块的链上原子份额与账本精确核对，显示数量或价格不能替代链上身份和数量证明。查询失败、缺字段或矛盾均不放行。

一般程序外持仓仍阻止启用。程序仅对严格证明已结算、收益分子为零、派生身份及另一结果份额均符合原规则的标准二元输方残仓采用既有例外；不接管、烧毁、赎回或入账外部残仓。正收益、未结算、Neg-Risk、未知身份及查询失败不适用。

pUSD 用于交易，POL 用于相关链上手续费；余额和授权必须按实际资金账户、签名账户及当次手续费核对。网页“检查账户”不下单、不自动授权；“授权赎回”会发生真实链上操作，需要用户明确操作，不能代替交易所授权。具体外部资格和授权流程以当次官方说明及实际账户核对为准。

## TEST 与 LIVE 后台互斥

启用 LIVE 前，全部十个 TEST 必须 PAUSED。程序等待 TEST 行情、发现扫描、结算和采样任务退出，并持久保存 LIVE 模式意图，才进入私有客户端激活。切换期间旧 START 失效，新 TEST 交易操作被拒绝；仅查看 LIVE 页面或解锁钱包不会自动启动交易。

LIVE 启用成功仍为 PAUSED，需要另行明确 START。后来的 PAUSE 会使仍在钱包锁、就绪检查或磁盘/账本核验中等待的旧 START 失效；重新启动需再次明确 START。`LIVE + PAUSED` 不等于只读：已有仓位仍可能卖出、止损或赎回；`auto_approve_redemption=false` 不会禁止已经获授权的赎回。只读核对应使用独立预检，不以启用 LIVE 再暂停代替。

重启后钱包保持锁定、LIVE 不自动启用；若有持久化 LIVE 意图，TEST 后台也保持停止。后端确认没有 LIVE 活动且允许恢复后，可明确选择“恢复TEST后台（保持暂停）”；全部账户仍需各自 START。私有清理或模式保存未确认时后台保持停止，不自动恢复交易。

## 已有 LIVE 数据与备份

LIVE 账本、订单身份、未知提交、待确认授权和赎回的 hash／nonce 均不能丢弃、复用或让两台服务器同时管理。关闭网页或取消请求不代表已经开始的线程或链上事务被撤销；必须先核对原结果。钱包导入准备阶段取消会等待当前线程结束后停止后续阶段；钱包文件发布开始后，取消仍等待发布、身份绑定及内存状态收尾，已存在文件继续拒绝覆盖。LIVE 关闭即使暂停持久化或断连失败，也先完成其余私有及原生任务收尾，再报告错误并释放账本/进程所有权。

网页 `.pmnb` 是导出时点的加密钱包和 LIVE 账本快照，当前格式上限为 4 GiB 原始 LIVE 数据库、2 GiB 加密包。PAUSE 后仍可能卖出及赎回，换服必须停止旧实例写入，再制作最终一致性备份并对账。恢复请求取消时，后台工作结束前仍保留操作锁和上传文件。完整迁移还应保全十个 TEST、模式意图和部署配置，见 [DEPLOY](DEPLOY.md)。

## 独立命令行只读检查

下面的公开地址预检不启动 LIVE runtime、不构造签名钱包，也不导入私钥：

```sh
.venv/bin/python -m pm_nautilus.preflight \
  --signer 0x你的公开签名地址 \
  --funder 0x你的公开资金地址 \
  --signature-type 2
```

自己的 RPC 可通过 `PM_PREFLIGHT_RPC_URL` 指定，不把带密钥的 URL 放入截图或提交。预检按固定区块进行公开读取，成功退出只表示查询完成；余额、授权、资格和账本核对仍须分别满足。完整实盘资金闭环尚未因 TEST、CI 或部署验收而得到证明。
