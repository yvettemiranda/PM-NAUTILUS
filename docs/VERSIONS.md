2026-10-29 起，GitHub 只保留两个分支作为程序版本入口：

| 分支 | 定位 | 修改规则 |
| --- | --- | --- |
| `main` | 当前最新版，包含十个独立 TEST、通用优化及现行文档。已验收应用代码 `2f6d6f6c860d87bd289300af9ce532f0f2045c74`。 | 后续正常更新这里；部署固定通过验证的完整 SHA。 |

原 `codex/test-10-accounts` 的最新代码已经归入 `main`。其他历史工作分支和重复基准标签移除；当前没有 GitHub Release，也不额外创建重复版本。旧 PR #18 已被后续 PR #19 的实现取代，关闭而不合并，不把旧重签逻辑带回当前程序。

只整理分支、标签和文档，不重写或压平 Git 提交历史。老提交、合并记录和历史 CI 属于追溯资料，不是额外维护的版本。清理前的全部引用和完整仓库已制作本地可恢复 bundle；删除分支不等于删除交易账本或服务器备份。

后续下载、开发和维护统一从 `main` 开始。已有源码目录应先检查未提交修改，再获取并切换到当前入口；不要继续使用已删除的旧分支名作为远端拉取参数。

```sh
git clone --branch main https://github.com/yvettemiranda/PM-NAUTILUS.git
```

`main` 的文档提交可以比已部署应用 SHA 更新。2026-10-29 整理仅改 Markdown；2026-10-30 源码另增加 [四项保护修复](EGM_FIXES_20261030.md)。已部署完整 SHA 和验收证据以 HANDOFF 为准，源码更新不表示服务器镜像已自动更新。GitHub 源码不是运行数据备份；换服和回滚按 [部署手册](DEPLOY.md)保全全部账本、模式意图、钱包及受保护配置。

根目录 [README](../README.md)、[HANDOFF](../HANDOFF.md) 和 [VALIDATION](VALIDATION.md)描述当前版本。带日期的审计与设计材料用于解释原始需求或当时的修复，其中的旧数字、旧版本、地区和钱包状态不能覆盖当前证据。
