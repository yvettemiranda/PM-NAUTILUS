# 界面与收益曲线（2026-10-23）

首页集中显示累计盈亏估算、总资产估算与可用现金。资金规则放入“资金明细”；暂无报价仍有简短提示，按原规则暂计成本、浮盈亏暂记零，既有已实现盈亏保留。这次只调整展示，不重算或改写账本。

持仓列表保留名称、方向、均价和可卖价；展开查看数量、成本、浮盈亏和目标，再展开“策略详情”查看预算、档位与市场进度。市场列表先显示选中结果、当前状态和买卖价，技术统计与起止时间放入详情。记录页直接读取历史，默认显示金额和已实现盈亏，成交价、数量和结果放入“成交明细”。详情展开、长标题和键盘焦点在刷新中保持。

收益走势默认最近七天；右拖看更早、左拖看更新记录，箭头按周翻看，“回到最新”继续跟随新采样。历史中查看的位置不会被后台刷新拉回。小时／日采样可切换，按日仍为 UTC 日期。少于一周时只显示已有记录；断线、重启与未知值保留断点，不把旧点连成虚构的收益。只改变视野，历史数据不删除、压缩或截断。

键盘左右键移动一天，PageUp／PageDown 移动一周，Home 到最早，End 到最新；Shift 加左右键读取当前视野内具体日期和盈亏。触屏纵向滚动页面仍可用。

模式／账本代次切换清除旧图；过时代次的异步结果不接管当前图。LIVE 钱包锁定、核对失败或过期时隐藏已绘制历史，保持原账户隐私边界。真正的数据中断、存储保护和自动暂停提示继续可见，常规诊断在“数据状态”中展开。
